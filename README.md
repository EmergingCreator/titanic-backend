## Titanic Survival Prediction

An end-to-end machine learning application that predicts passenger survival on the Titanic using demographic and travel-related features. The project covers data analysis, preprocessing, feature engineering, model training, and deployment through an interactive web interface.

### Features

- Exploratory Data Analysis (EDA) to identify survival patterns
- Data cleaning and preprocessing
- Feature engineering and selection
- Machine learning model training and evaluation
- Survival prediction based on passenger information
- Interactive web interface for generating predictions
- REST API integration for model inference

### Technology Stack

- **Programming Language:** Python
- **Data Analysis:** Pandas, NumPy
- **Machine Learning:** Scikit-learn, XGBoost
- **Backend:** FastAPI
- **Frontend:** React
- **Visualization:** Matplotlib, Seaborn
